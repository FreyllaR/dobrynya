# Добрыня — голосовой помощник для Mac

Голосовой ассистент в духе Джарвиса: зовёте «Добрыня», дальше просто разговариваете.
Вежливый, невозмутимый, с сухой иронией и обращением «сэр». На экране — анимированный шар,
как в голосовом режиме ChatGPT.

Всё бесплатно: мозг — Gemini API на бесплатном лимите, распознавание и голос работают прямо на Маке.

| Часть | Технология |
|---|---|
| Слово активации | Vosk (офлайн) |
| Распознавание речи | Whisper large-v3-turbo (MLX, Apple Silicon) |
| Мозг | Gemini Flash-Lite с потоковым ответом (запасной вариант — Qwen3 8B через Ollama) |
| Голос | Qwen3-TTS локально: низкий голос богатыря, «эх» и «ха-ха»; запасной — Piper |
| Интерфейс | WebGL-шар в белом окне по центру экрана (pywebview) |

## Требования
- Mac на Apple Silicon (M1 и новее)
- Python 3.10+ и [Homebrew](https://brew.sh)
- Бесплатный ключ Gemini: https://aistudio.google.com/apikey

## Запуск

```bash
git clone git@github.com:FreyllaR/dobrynya.git
cd dobrynya
```

Создайте файл `.env` со своим ключом Gemini (вместо `AIza...` — ваш настоящий ключ):

```bash
echo "GEMINI_API_KEY=AIza..." > .env
```

И запустите:

```bash
./run.sh
```

Первый запуск сам поставит зависимости и скачает модели (около 3 ГБ), это займёт несколько минут.
macOS спросит доступ к микрофону — разрешите.

Текстовый режим для отладки навыков: `./run.sh --text`

## Как говорить
- «Добрыня, какая погода?» — можно одной фразой или сказать имя, дождаться сигнала и продолжить.
- После ответа Добрыня ещё 8 секунд слушает без имени — просто продолжайте разговор.
- «Стоп», «спасибо, всё» или «пока» — закончить разговор.

## Что умеет
- болтать и отвечать на вопросы, помнить контекст разговора и факты о вас
- открывать приложения, сайты и файлы, искать файлы, менять громкость, управлять музыкой
- напоминания, таймеры, заметки
- погода, новости, поиск в интернете

Примеры: «открой телеграм», «поставь таймер на 10 минут», «запиши: купить молоко»,
«что у меня в заметках», «запомни, что я люблю джаз», «громкость 30», «следующий трек».

## Шар
| Состояние | Анимация |
|---|---|
| Ждёт имя | медленно дышит |
| Слушает | реагирует на громкость голоса |
| Думает | облака закручиваются воронкой |
| Говорит | пульсирует в такт речи, внизу субтитры |

Окно открывается по центру экрана, `Esc` закрывает его (голос продолжит работать).
Чтобы окно было всегда поверх остальных — `ORB_ON_TOP = True` в `config.py`.
`orb.html?demo` в браузере показывает все состояния без запуска Добрыни.

## Настройка
Всё в `config.py`:
- `NAME`, `USER_NAME`, `DEFAULT_CITY` — имя, как обращаться к вам, город для погоды
- `QWEN_VOICE` — образец голоса (`voices/dobrynya.wav`): Добрыня говорит так же
- `VOICE_NONVERBAL` — «хм», «эх» и «ха-ха» в ответах
- `TTS_ENGINE` — `"qwen"` (по умолчанию), `"piper"` (проще, мгновенно), `"gemini"` (облако, 10 ответов в день)
- `STRESS_FIXES` — ручные ударения: `"творог": "твор+ог"` (`+` перед ударной гласной)
- `CONVERSATION_TIMEOUT` — сколько слушать после ответа без имени
- `SHOW_ORB`, `SHOW_TIMINGS` — окно с шаром и замеры задержек в терминале
- `LLM_PROVIDER = "ollama"` — работать без интернета на локальной модели

Характер — в `brain.py`, навыки — в `tools.py` (новая функция с docstring + добавить её в `TOOLS`).
Заметки, напоминания и память хранятся в `data/`.

Gemini API недоступен из некоторых стран (в том числе из России) — тогда нужен VPN.
